# 🔢 Basic C++ Calculator

A simple command-line calculator written in C++ that performs basic arithmetic operations: addition, subtraction, multiplication, division, and modulus.

## ✨ Features
- Takes two integers and an operator from the user
- Supports `+`, `-`, `*`, `/`, and `%`
- Handles division/modulus by zero
- Uses a `switch` statement for operation control

## 🛠️ Technologies Used
- C++
- Standard I/O (`iostream`)
- `switch-case` for operator handling

## 🚀 How to Run

1. Make sure a C++ compiler like `g++` is installed.
2. Save the code in a file named `calculator.cpp`.
3. Open terminal and run:

g++ calculator.cpp -o calculator
./calculator
